# Asset licensing inventory

D01–D03 use **Godot procedural primitive meshes and materials**, authored in text scene files:

- CapsuleMesh, SphereMesh, BoxMesh, BoxShape3D and CapsuleShape3D.
- Basic StandardMaterial3D colors, a DirectionalLight3D and engine-default font.
- No external textures, icons, fonts or sound assets.

D04 adds **`demo/assets/action5_training_character.glb`**, an original low-poly humanoid made specifically for ACTION-5. It contains a 15-joint skinned skeleton (including articulated knees and elbows), two separately skinned mesh groups (body/head), with split upper-arm/forearm and thigh/shin meshes, and ten authored animation clips (idle, walk, run, punch, kick, hit, death, reload, crouch, crouch_walk). The geometry, rig and keyframes are reproducibly generated by the checked-in source `tools/generate_training_character.mjs` (run with Node.js); they were not copied from any third-party model or motion capture. License: **MIT** (repository `LICENSE`). No external attribution is required.

D06-01 adds original procedural BoxMesh world Bat/Shovel props and static
camera-local F4 views (`demo/equipment/`) authored directly in Godot text
scenes. The shaft/blade/head geometry, colors and poses are newly authored
for ACTION-5, without external textures, proprietary models or downloaded
assets. They are MIT-licensed with the project. D06-01 tests include a
procedural two-mesh third-weapon fixture.

All scene, script and configuration sources are part of ACTION-5 and licensed under the repository MIT LICENSE.

When adding third-party material in later deliverables, record its exact filename, author, source URL, license (including any attribution requirements), and whether redistribution is permitted **before** committing it.
